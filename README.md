# Lampage

Desktop PDF + Markdown reader (Electron + React + TypeScript).

## Install

cd /workspace/lampage
bun install

## Run

bun run dev

## Build

bun run build
bun run typecheck
bun run package

## Layout

src/main, src/preload, src/renderer

## Features

Shell: multi-file, resizable sidebars, zoom, print, find, dialogs, drag-drop.
PDF: pdf.js, thumbnails, outline, page ops, signatures, save.
Markdown: TipTap read/edit, TOC, code copy, save, print-to-PDF.
